Final Databricks-only design

Centralized Competitive-Intelligence Table with JSON Transformations and LLM-Generated Selling Points

A full-refresh Databricks workflow that reads the source table, applies governed transformation rules defined in JSON, creates the model-ready record, generates structured selling points through OpenAI, validates each response, and publishes one centralized Delta table. The current design intentionally contains no FastAPI and no change-detection logic.

1. Executive Decision

Recommended implementation: one scheduled Databricks workflow performs a complete rebuild of the centralized table using the current source table, JSON-defined transformation rules, and structured LLM generation.

Transformation

Load a versioned JSON rule file and compile only approved operations into PySpark column expressions.

Generation

Send the transformed record to OpenAI and require a strict JSON response containing an array of selling points.

Publication

Write a run-scoped staging Delta table, validate it, then replace the contents of the central table.

Data points unavailable: source schema, row volume, schedule, OpenAI model, rate limits, and exact JSON rule structure. The guide uses parameterized names and supports a full-refresh batch. Final concurrency and compute settings must be based on actual volume and API limits.

Reject unknown rule types, duplicate target fields, missing required keys, unsupported casts, and schema-version mismatches.

Apply deterministic transformations

Perform mappings, casts, null handling, derived fields, filtering, and formatting entirely in Spark.

Stage before publishing

7. Governed PySpark Transformation Engine

The engine converts JSON rules into Spark expressions and fails closed when a rule is unknown or malformed.

from typing import Any, Literal
from pydantic import BaseModel, Field, model_validator

class FilterRule(BaseModel):
    type: Literal["equals", "not_null"]
    column: str
    value: Any | None = None

class TransformationRule(BaseModel):
    type: Literal[
        "rename", "trim", "cast", "coalesce",
        "concat_ws", "case_when", "array_clean"
    ]
    source: str | None = None
    sources: list[str] | None = None
    target: str
    data_type: str | None = None
    separator: str | None = None
    cases: list[dict[str, Any]] | None = None
    otherwise: Any | None = None
    trim: bool | None = None
    remove_empty: bool | None = None
    deduplicate: bool | None = None
    sort: bool | None = None

class SourceConfig(BaseModel):
    table: str
    business_key: list[str] = Field(min_length=1)
    filters: list[FilterRule] = []

class PipelineConfig(BaseModel):
    config_version: str
    pipeline_name: str
    source: SourceConfig
    transformations: list[TransformationRule]
    required_fields: list[str]
    llm_input_fields: list[str]
    target_fields: list[str]

    @model_validator(mode="after")
    def validate_unique_targets(self):
        targets = [rule.target for rule in self.transformations]
        duplicates = {x for x in targets if targets.count(x) > 1}
        if duplicates:
            raise ValueError(f"Duplicate targets: {sorted(duplicates)}")
        return self
from pyspark.sql import DataFrame
from pyspark.sql import functions as F

ALLOWED_CAST_TYPES = {
    "string", "boolean", "date", "timestamp",
    "int", "bigint", "double", "decimal(18,2)"
}

def compile_predicate(rule):
    column = F.col(rule["column"])
    if rule["type"] == "equals":
        return column == F.lit(rule["value"])
    if rule["type"] == "not_null":
        return column.isNotNull()
    raise ValueError(f"Unsupported predicate: {rule['type']}")

def apply_rule(df: DataFrame, rule: dict) -> DataFrame:
    rule_type = rule["type"]
    target = rule["target"]

    if rule_type == "rename":
        return df.withColumn(target, F.col(rule["source"]))
    if rule_type == "trim":
        return df.withColumn(target, F.trim(F.col(rule["source"])))
    if rule_type == "cast":
        data_type = rule["data_type"]
        if data_type not in ALLOWED_CAST_TYPES:
            raise ValueError(f"Unsupported cast: {data_type}")
        return df.withColumn(target, F.col(rule["source"]).cast(data_type))
    if rule_type == "coalesce":
        return df.withColumn(target, F.coalesce(*[F.col(x) for x in rule["sources"]]))
    if rule_type == "concat_ws":
        return df.withColumn(target, F.concat_ws(rule.get("separator", " "), *[F.col(x) for x in rule["sources"]]))
    if rule_type == "case_when":
        expression = None
        for case in rule.get("cases", []):
            predicate = compile_predicate(case["when"])
            expression = F.when(predicate, F.lit(case["then"])) if expression is None else expression.when(predicate, F.lit(case["then"]))
        if expression is None:
            raise ValueError("case_when requires at least one case")
        return df.withColumn(target, expression.otherwise(F.lit(rule.get("otherwise"))))
    if rule_type == "array_clean":
        source = F.coalesce(F.col(rule["source"]), F.array().cast("array<string>"))
        result = F.transform(source, lambda value: F.trim(value))
        if rule.get("remove_empty", True):
            result = F.filter(result, lambda value: value != "")
        if rule.get("deduplicate", True):
            result = F.array_distinct(result)
        if rule.get("sort", False):
            result = F.array_sort(result)
        return df.withColumn(target, result)
    raise ValueError(f"Unsupported transformation: {rule_type}")

def apply_config(df: DataFrame, config: dict) -> DataFrame:
    transformed = df
    for filter_rule in config["source"].get("filters", []):
        transformed = transformed.filter(compile_predicate(filter_rule))
    for rule in config["transformations"]:
        transformed = apply_rule(transformed, rule)
    return transformed.select(*config["target_fields"])
from pyspark.sql import functions as F

def build_model_input(df, config):
    fields = config["llm_input_fields"]
    return (
        df
        .withColumn(
            "llm_input_struct",
            F.struct(*[F.col(field).alias(field) for field in fields]),
        )
        .withColumn(
            "llm_input_json",
            F.to_json(
                F.col("llm_input_struct"),
                options={
                    "ignoreNullFields": "true",
                    "dateFormat": "yyyy-MM-dd",
                    "timestampFormat": "yyyy-MM-dd'T'HH:mm:ssXXX"
                },
            ),
        )
    )
Clarification: this JSON string is generated after applying the configuration-driven transformations. It is the model payload. The original JSON file remains the transformation specification.

8. LLM Generation Contract

The model converts transformed facts into concise selling points. It must not calculate source fields, alter business meaning, or introduce unsupported comparative claims.

sequenceDiagram autonumber participant DB as Databricks Python Task participant SEC as Databricks Secrets participant OAI as OpenAI API participant VAL as Output Validator participant STG as Staging Delta Table DB->>SEC: Retrieve API key SEC-->>DB: Secret value DB->>DB: Build transformed input JSON DB->>OAI: Request strict structured response OAI-->>DB: selling_points JSON DB->>VAL: Validate schema and content alt Valid VAL-->>DB: Typed selling_points array DB->>STG: Write successful enriched row else Invalid or API failure VAL-->>DB: Error category and details DB->>STG: Write failed status or quarantine row end

Response schema

from pydantic import BaseModel, Field

class SellingPointsOutput(BaseModel):
    selling_points: list[str] = Field(
        min_length=2,
        max_length=5,
        description="Distinct factual selling points derived only from the supplied transformed record."
    )

System instruction

You generate concise competitive-intelligence selling points.

Use only the facts in the supplied JSON record.
Do not add external facts or assumptions.
Do not calculate or transform business values.
Do not compare products unless the record explicitly contains the comparison.
Do not use unsupported superlatives such as best, cheapest, leading,
superior, unmatched, or most reliable.

Generate 2 to 5 distinct selling points.

Each selling point must:
- Be one complete sentence.
- Contain no more than 25 words.
- Preserve material qualifiers such as geography, eligibility,
  availability, effective date, and price conditions.
- Describe a factual attribute in clear business language.
- Avoid repeating another selling point.

Return only the required structured output.

9. Safe Batch Processing Without Change Detection

The current job processes every eligible row. Select an execution method based on source volume while preventing uncontrolled API calls and Spark retry duplication.

VolumeRecommended patternMain caveat
SmalltoLocalIterator() with a bounded thread pool in one Python task.Driver memory and run duration must remain safe.
ModerateControlled partitions using mapPartitions, one OpenAI client per partition.Spark task retries can repeat API calls.
Large offline batchGenerate JSONL in Databricks, submit to OpenAI Batch API, poll in a later task, then reconcile results.More workflow complexity, but improved throughput control.
Avoid a normal row-level Spark UDF that calls OpenAI. It hides network behavior inside Spark, can create uncontrolled concurrency, may repeat calls during task retries, and is difficult to rate-limit.

Small-volume bounded-concurrency example

from concurrent.futures import ThreadPoolExecutor, as_completed
from datetime import datetime, timezone
import random, time, uuid

MAX_CONCURRENCY = 6
MAX_ATTEMPTS = 3

def generate_with_retry(row):
    last_error = None
    for attempt in range(1, MAX_ATTEMPTS + 1):
        try:
            parsed = generate_selling_points(row.llm_input_json)
            return {
                **row.asDict(recursive=True),
                "selling_points": parsed.selling_points,
                "generation_status": "SUCCESS",
                "validation_status": "VALID",
                "generation_attempt_count": attempt,
                "error_code": None,
                "error_message": None,
            }
        except Exception as exc:
            last_error = exc
            if attempt == MAX_ATTEMPTS:
                break
            time.sleep(min(2 ** attempt, 10) + random.random())
    return {
        **row.asDict(recursive=True),
        "selling_points": None,
        "generation_status": "FAILED",
        "validation_status": "NOT_VALIDATED",
        "generation_attempt_count": MAX_ATTEMPTS,
        "error_code": type(last_error).__name__,
        "error_message": str(last_error)[:1000],
    }

run_id = str(uuid.uuid4())
generated_at = datetime.now(timezone.utc)
results = []

with ThreadPoolExecutor(max_workers=MAX_CONCURRENCY) as executor:
    futures = {
        executor.submit(generate_with_retry, row): row.entity_id
        for row in transformed_df.toLocalIterator()
    }
    for future in as_completed(futures):
        result = future.result()
        result["pipeline_run_id"] = run_id
        result["generated_at"] = generated_at
        results.append(result)
For anything beyond small volume, avoid retaining all results in the driver's list. Write bounded chunks to staging or use a partition-oriented implementation.

13. Enterprise Controls and Caveats

Security and governance

API keyStore in Databricks Secrets and grant only the workflow run identity.
Data minimizationSend only approved transformed fields to OpenAI.
Configuration accessVersion and restrict transformation JSON changes.
Unity CatalogSeparate staging, Gold, and operations schemas with controlled ownership.
Prompt controlVersion prompts and review material wording changes.
Error storageRedact secrets and avoid retaining complete model inputs without approval.

Reliability and operations

Full-refresh costEvery run regenerates all eligible rows. Estimate requests, tokens, duration, and spend.
Rate limitsSet concurrency below project request and token limits.
RetriesRetry only transient failures with bounded attempts, backoff, and jitter.
Partial failuresDefine whether any failed row blocks publication. Default is fail closed unless approved otherwise.
ReproducibilityStore configuration, prompt, schema, model, run ID, and source snapshot timestamps.
RollbackUse Delta table history or the approved restore procedure.

Required run metrics

Data

Source, eligible, transformed, rejected, and published rows.

LLM

Requests, successes, failures, retries, tokens, refusals.

Performance

Total duration, transform time, average and p95 model latency, publish time.

Quality

Invalid JSON, bad point count, duplicates, prohibited claims, missing qualifiers.

Future enhancement, not current scope: consider change detection only when repeated full-table regeneration becomes expensive, slow, or causes unnecessary wording drift.
